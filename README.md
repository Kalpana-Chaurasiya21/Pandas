# Pandas

A collection of Python scripts and notebooks exploring data analysis and manipulation using the [Pandas](https://pandas.pydata.org/) library.

##  About

This repository contains examples, exercises, and mini-projects covering core Pandas concepts such as:

- Reading and writing data (CSV, Excel, JSON, etc.)
- Data cleaning and preprocessing
- Filtering, sorting, and grouping data
- Handling missing values
- Merging and joining DataFrames
- Data aggregation and summarization
- Exploratory Data Analysis (EDA)

##  Tech Stack

- **Python 3.x**
- **Pandas**
- **NumPy** (optional, for numerical operations)
- **Jupyter Notebook** (for interactive examples)
